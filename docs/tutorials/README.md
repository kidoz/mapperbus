# Tutorials

Tutorials are guided lessons with a concrete result. Start with a working build,
then use it to run a game.

1. [Build and test MapperBus](build-and-test.md) — compile a headless build and
   run a test without a ROM, display, or audio device.
2. [Run your first game](first-game.md) — build the SDL3 frontend, load a ROM,
   use the keyboard, and change the display scale.

For a particular build variant or settings change, use the
[how-to guides](../how-to/README.md).
